# Skill Pack

This folder contains a distributable copy of the peptide research operations skill.

Use it when you want to hand the methodology to another Codex-style environment without pointing them at this repo's live `.agents/skills/` folder.

Contents:

- [peptide-research-ops](peptide-research-ops)

Installation pattern:

1. copy the skill folder into the target environment's skills directory
2. keep the folder name as `peptide-research-ops`
3. do not rename the internal files

This is a packaged copy of the live skill, not the source of truth.
