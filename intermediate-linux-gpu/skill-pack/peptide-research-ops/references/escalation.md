# Escalation Guide

## Ask For More Papers When

- a named literature peptide is being used as a benchmark
- a sequence provenance dispute exists
- a medicinal-chemistry substitution changes the biological claim
- the project relies on exact PK / potency numbers from a paper

## Ask The Scientific Reviewer When

- the lane failed and there are multiple valid reframes
- two methods disagree in a project-changing way
- the target mechanism or strategic claim changes
- the project is about to produce a shortlist on ambiguous evidence

## Ask Another Role-Oriented Lane When

- the task is parallel and orthogonal
- the other lane has a materially different capability
- the main lane would otherwise block on noncritical side work

## Do Not Escalate For

- simple repo navigation
- file path discovery
- basic TSV / JSON aggregation
- routine commit hygiene

## Preferred message shape

Use short messages with:

1. current gate
2. what passed or failed
3. exact files
4. the specific question

Bad:
- “What do you think?”

Good:
- “Phase 2 failed because scrambled survives and real does not separate from decoys. Lane can be reframed as geometry-only or discarded. Which direction do you want?”
