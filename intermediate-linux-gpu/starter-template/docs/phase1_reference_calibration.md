# Phase 1 — Reference Calibration

## Goal

Prove that the current lane can distinguish an actual reference from obvious negatives.

## Required Inputs

- primary positive control
- weaker or proxy positive
- scrambled negative
- poly-Ala or equivalent composition-floor negative

## Pass Condition

A sane lane should show:

- the primary positive behaving better than obvious negatives
- the weaker/proxy positive behaving plausibly
- scrambled and composition-floor negatives not surviving like real binders

## If This Fails

Do not move to a large candidate panel.

First classify the failure:

- spec-layer issue
- numbering issue
- sequence-insensitive lane
- geometry-only lane

Then write down the interpretation before more compute.
