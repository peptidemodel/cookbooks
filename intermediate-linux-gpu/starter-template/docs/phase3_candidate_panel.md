# Phase 3 — Candidate Panel

## Goal

Build an interpretable candidate panel only after the reference and target-decoy prerequisites are satisfied.

## Minimum Requirements

- labeled candidate rows
- explicit SAR series
- hypothesis per series
- references still present for comparison
- negatives still present for comparison

## Pass Condition

The panel is interpretable and the design moves are explicit.

## Fail Condition

The panel is just a bag of sequences with no series logic or no embedded controls.
