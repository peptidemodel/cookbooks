# Phase 5 — Closeout

## Goal

Produce a short list with honest caveats.

## Each Finalist Must Include

- sequence
- why it survived
- what lane supports it
- main metric
- main caveat
- whether it beat a real reference or only a proxy

## Pass Condition

The shortlist is defensible and the caveats are explicit.

## Fail Condition

The closeout overclaims what the current evidence supports.
