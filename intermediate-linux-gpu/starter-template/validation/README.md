# Validation

This folder is the neutral home for your stronger validation lane.

Examples:

- AF2 / Colab notebook bundles
- stronger structure-prediction scripts
- PyRosetta target-decoy validation
- alternative-model validation

Use this folder if you want the public starter template to stay tool-neutral while still making it obvious that a “strong lane” needs a defined home.

Document here:

- which validation stack is used
- exact commands or notebook entrypoints
- what that lane is allowed to claim
- current status
