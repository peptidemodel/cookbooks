# Claims Ladder

Use this to keep statements honest.

## Claim Level 1: Environment Proven

Allowed claim:

- “The MLX environment can run a peptide-target prediction and write outputs.”

Not allowed:

- any biological ranking claim

## Claim Level 2: Preview Geometry Exists

Allowed claim:

- “Preview mode produces a coherent complex for this query family.”

Not allowed:

- strong sequence-specific discrimination claims

## Claim Level 3: Preview Controls Are Directionally Sensible

Allowed claim:

- “The preview lane is useful for coarse triage or existence proof.”

Not allowed:

- final promotion based on one-sample metrics alone

## Claim Level 4: Upgrade Validation Passed

Allowed claim:

- “This candidate or reference survived stronger OF3-MLX scrutiny.”

Still be careful with:

- affinity language
- medicinal chemistry claims
- synthesis recommendations unsupported by orthogonal data

## Claim Level 5: Orthogonally Supported

Allowed claim:

- “This result is a credible promoted structure hypothesis with explicit
  caveats.”

Even here, keep the caveats.
